# 3D Prints

STL files and FreeCAD parametric macros for all printed parts on the robot.

| File | Description |
|------|-------------|
| `battery_holder.stl` | LiPo battery mount |
| `buck_converter_mount.stl` | Buck converter / voltage regulator bracket |
| `camera_holder_robot_face.stl` | Stereo camera mount on the robot face |
| `HiwonderPanTiltBase.stl` | Base bracket for the Hiwonder pan-tilt head |
| `light_diffuser_Sphere.stl` | Hemisphere light diffuser sphere |
| `pi_holder.stl` | Raspberry Pi 5 mount |
| `pololu_converter_mount.stl` | Pololu voltage converter bracket |
| `servo_head_connection-Body.stl` | Pan-tilt servo connection bracket |
| `Speaker_Box.stl` | USB speaker enclosure |
| `Switch_holderv2.stl` | Power switch holder |
| `Waveshare_Display_holder.stl` | Waveshare 7" display mount |
| `wife_boobs_v4.stl` | 3d printed boobs |

FreeCAD parametric source macros are in `macros/`.
